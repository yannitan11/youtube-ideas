Your board syncs through a private GitHub Gist — free, no account beyond your GitHub. Do this once per device with the same token:

  1. Create a token — the gist scope is pre-ticked; set expiration to "No expiration", then Generate & copy it.
  2. Paste it below. Your first device creates the gist; the second one finds it.

The token is stored only in this browser and only touches your gists.

This device is connected. Edits sync automatically a moment after you make them, and whenever you return to the tab.

To add another device: copy your token below, open the site there, tap Set up sync, and paste it in.

GitHub only shows a token once, so this is the copy — it can read and write your gists, so keep it to your own devices.
